Line Follower Robot (LFR)

The Challenge

To build a high-speed robot capable of following a complex black line on a white surface without losing trajectory on sharp turns.

The Solution

Implemented a PID (Proportional-Integral-Derivative) control algorithm using an Arduino Nano. This calculates the error value from the IR sensor array and adjusts motor speed continuously for smooth path correction.

Tech Stack

Arduino Nano QTR-8RC Sensors L298N Driver C++
